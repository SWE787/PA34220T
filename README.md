# PA34220T
Performance data for Piper Seneca III PA-34-220T
This is a small project that I created to learn. Being a professional pilot I aim for the most efficient flight every flight. Problem is the tools for older planes are not always available. When I fly the B787 we have both very well prepared flight plans that calculate every aspect of the route and which speed to fly based on cost/hr and fuel price.
My purpose of this small project is to create small simple tool for pilots flying the Piper Seneca III, PA-34-220T. This is an aircraft which I have flown many hours in.
The file is in a standard html file so it can run in a web browser. The size is so small that it can run off line.
Any feedback and suggestions is most welcome.
